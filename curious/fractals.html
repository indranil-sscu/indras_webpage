How to use.
  1. Drag to pan. Scroll, pinch or double-click (double-tap) to zoom in, or use the zoom buttons. Keyboard: focus the picture, arrows pan, + and − zoom.
  2. Click (tap) a point to see its orbit: the sequence z₀, z₁, z₂, … drawn on the picture and charted below.
  3. In the Mandelbrot set, press Julia set at this point to see the Julia set for the c you picked. Raise the iterations when you zoom deep and the edges turn blurry.

The Mandelbrot set

What is going on?

Pick a complex number c (a point on the picture) and start from z = 0. Repeat one rule: z → z² + c. For some c the numbers stay bounded forever; for others they eventually grow without limit. The Mandelbrot set is the set of all c that stay bounded, drawn here in the darkest colour. Once |z| passes 2 it is certain to escape, so each point outside is coloured by how many steps it took to pass 2: its escape time.

A Julia set uses the same rule the other way round: keep c fixed and vary the starting point z₀. Every point c has its own Julia set. If c lies inside the Mandelbrot set its Julia set is one connected piece; if c lies outside, the Julia set shatters into dust. That is in fact how the Mandelbrot set is defined in the mathematical literature: the map of which Julia sets are connected.

Click around and watch the orbits. Inside the large heart-shaped region (the main cardioid) the orbit spirals into a single fixed point; in the big disc to its left it settles into a cycle of two; in each smaller bulb, a longer cycle. Near the edge, orbits wander for a long time before deciding, which is why the boundary needs more iterations to draw sharply. Zoom into the boundary and you will find small copies of the whole set, the hallmark of a fractal.

The mathematics
zn+1 = zn² + c;   Mandelbrot set M = { c : z₀ = 0 stays bounded };   filled Julia set Kc = { z₀ : orbit stays bounded }
escape criterion: if |zn| > max(2, |c|) the orbit tends to ∞;   smooth count ν = n − log₂( ln|zn| / ln R ), bail-out R = 256
main cardioid: q(q + x − ¼) ≤ ¼y², q = (x − ¼)² + y²;   period-2 disc: (x + 1)² + y² ≤ 1/16
area of M ≈ 1.50659;   for c = 0, K₀ is the unit disc and ν = log₂(ln R / ln|z₀|) exactly

The picture is computed point by point in double-precision arithmetic, a quick preview first and then at full screen resolution. Below a view width of about 10⁻¹³ the numbers run out of precision and the image turns blocky. Automated tests check escape times against exact values (for c = 1 the orbit 0, 1, 2, 5 escapes at step 3; the Julia set of c = 0 is the unit disc), the interior shortcut against brute force, the symmetry of the images, and the area of the set.
