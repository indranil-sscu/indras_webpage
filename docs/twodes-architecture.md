# 2DES simulator: architecture

The simulator at `/tools/2des/` is split into a numerical engine, an interface model and the page.
Only the page touches the DOM; everything else runs unchanged in Node, where it is tested.

| Layer | File | Role |
|---|---|---|
| Engine | `assets/js/twodes-core.js` | Units, radix-2 FFT and direct (nonuniform) transforms, Fourier sign conventions and the rotating frame, model responses (two-level, three-level ladder, excitonic dimer with orientational averaging, displaced-oscillator vibronic model, Brownian-oscillator monomer), the restricted expression parser, CSV import and validation, `run(job)`, waiting-time traces, convergence checks, coherence maps, and (v2) pathway decomposition, difference spectra, 1D cuts, direct peak measures and peak fits. |
| Worker | `assets/js/twodes-worker.js` | Runs engine calls off the main thread (`run`, `trace`, `convergence`, `cmPrepare`, `cmMaps`, `decompose`); the page falls back to the main thread if workers are unavailable. |
| Interface model | `assets/js/twodes-ui.js` | Explore-mode systems and the mapping of their four beginner controls onto model parameters; Advanced-mode parameter sections; the capability matrix (which model implements which effect); `buildJob(state)`, the single place where interface state becomes an engine job. |
| Page | `twodes.html` | Three modes (Explore, Advanced Models, Research Workbench) over one shared state; the 2D map with zoom, pan, crosshair and readout; waiting-time explorer; cuts and fits; pathway decomposition; A/B comparison; numerical quality; documentation. |
| Charts | `assets/js/plotkit.js`, `assets/js/theme.js` | Axes, lines and theme-aware, high-DPI canvases. |

## Data flow

```
interface state ──twodes-ui.buildJob──▶ job ──worker/engine run()──▶ {R, NR, total, resp, info, warnings}
                                                     │
                     specOf(result, view) ──▶ displayed quantity ──▶ renderMap / cuts / small multiples
```

A job is `{source: "model" | "expr" | "data", model, params, comps, expr, data, T, numerics}`; `numerics` holds the
time step, points, zero padding, window, broadening, first-point halving, convention and carrier. All spectra on screen
come from `run()` on such a job; nothing is pre-rendered.

## Conventions (unchanged in v2)

Rephasing kernel e^{−iω₁t₁}e^{+iω₃t₃}, non-rephasing e^{+iω₁t₁}e^{+iω₃t₃} by default (two alternatives selectable in the
Workbench); absorptive = Re[S_R + S_NR] with GSB and SE positive, ESA negative; rotating frame defined through the
standard kernel. All calculations are impulsive-limit; no finite-pulse model exists, and the interface says so.

## Tests

* `tests/twodes-core.test.js`: validation against analytical results (peak positions, 2Γ widths, T₁ decay,
  conventions, Lorentzian lineshape, zero padding, FFT vs direct sums, dimer and vibronic limits, the Sahu & Tiwari
  2023 numbers, coherence maps, parser safety, CSV import).
* `tests/twodes-regression.test.js`: the engine reproduces `tests/fixtures/twodes-golden.json`, generated by
  `tests/make-twodes-golden.js` on the v1.1 engine before the v2 redesign (15 jobs across all models, conventions,
  windows and pathway selections, plus a coherence map).
* `tests/twodes-ui.test.js`: presets equal the v1 examples, the job builder matches v1 jobs, Explore controls map to
  parameters and back, every parameter has a section, capabilities never claim an absent model, decomposition is
  exact, difference spectra refuse mismatched grids, cuts and fits recover known lineshapes.
